# manga-node

The Rust library and production binaries for the standalone MangaPub core.

Build from the workspace root with `cargo build --locked --release`, or use `cargo build --locked --manifest-path server/Cargo.toml --release`.

See the [root README](../README.md), [running guide](../docs/RUNNING.md), and [protocol guide](../docs/PROTOCOL.md). This package contains no test targets or embedded test modules.
