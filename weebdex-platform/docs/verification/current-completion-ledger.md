## Evidence boundaries

- Existing historical results retain their original source and scope. No past
  failure, pending control, skip or interrupted execution is relabeled as a pass.
- Internal execution reports, process-owner journals, host-resource snapshots
  and raw logs are withheld. This document does not substitute for those bytes.
- Removing reports or replacing documentation changes the export membership.
  An old source-manifest digest or successful private-tree run does not certify
  this smaller public profile. A fresh exact-profile run is required.
- Authored immutable source fixtures remain test inputs. They are not excluded
  merely because they use a text or compressed-file suffix.
- Native browser, backend/SQL/HTTP, full recovery, sustained capacity and
  release/deployment acceptance are separate from finite source tests.
- Earlier public history is preserved, not certified to contain only sanitized
  evidence. This profile does not erase or reclassify that history.

The retained upload diagnostics remain historical evidence for their actual
inputs. Current upload, transport, chapter-access and Vite configuration bytes
must not be replaced by older bytes to retain an earlier diagnostic outcome.
Current-source controls and any separately authorized native run need their own
source associations. A historical browser result is not current application
acceptance.

See [the source-profile and withheld-evidence notice](source-profile-and-withheld-evidence.md)
for the distinction between historical documentation, portable recipes and
new qualification. This summary intentionally omits internal machine locations,
resource-admission journals and unverified completion counts.
