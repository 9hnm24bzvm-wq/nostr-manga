profile is a proposed selection; it is not qualified until the exact resulting
tree and manifest have been reviewed and actually rerun.

Earlier source documentation records finite synthetic discussion and context
transport checks. Their original machine-bound JSON receipts are intentionally

## Selection and reproducibility

The source selection withholds raw logs, host-resource snapshots, process-owner
journals and internal execution/build/compiler reports. Three authored documents
or recipes receive explicitly labeled safe derivatives; the original internal
blobs remain excluded. Content-cleared benign summaries/placeholders and genuine
immutable source preimages remain included. A suffix alone is not a privacy test.

The previous finite source manifest included historical reports through broad
directory membership. Omitting those bytes invalidates that old manifest for
this export, not the feasibility of qualifying a new explicit profile. Source,
fixture, mode, path-set and tamper controls must remain mandatory. No excluded
report may be treated as a missing test that silently passes.

The smaller profile cannot replay historical build-driver recipes that require
withheld build integration receipts as if those historical receipts were present.
A future build must generate new source-associated output; an editorial summary
cannot substitute for a receipt checked by executable code.

and does not offer the private candidate's public-signed-features dispatch option.

The authentic historical transport used by legacy pipe controls is an immutable

raw evidence or private data. No publication, CI run or deployment is authorized
by this notice.
